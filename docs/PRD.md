# WITHU PRD (Product Requirements Document)

## 1. 서비스 개요

WITHU는 AI 기반 개인 맞춤 건강 미션과 그룹 기반 동기부여를 결합하여 사용자가 건강한 습관을 지속할 수 있도록 돕는 **힐링 웰니스 그룹 서비스**이다.

- AI는 사용자의 목표와 신체 정보를 분석하여 개인 맞춤형 미션을 생성하고, 식단 수행 결과를 종합적으로 분석하여 다음 미션을 생성한다.
- 사용자는 친구들과 건강 관리 과정을 공유하며 캐릭터 성장과 그룹 활동을 통해 지속적인 동기부여를 얻어 건강한 습관을 지속할 수 있는 구조를 만든다.

---

## 2. 사용자 흐름 (User Flow)

```
로그인
  ↓
캐릭터 생성
  ↓
온보딩
  ↓
그룹 참여
  ↓
AI 개인 맞춤 미션 생성
  ↓
식단 사진 업로드
  ↓
그룹 피드 공유
  ↓
AI 분석
  ↓
캐릭터 상태 변화
  ↓
AI 다음 미션 생성
```

## 3. 로그인

### 기능 설명
사용자는 이메일과 비밀번호를 입력하여 계정을 생성하고 서비스를 이용한다. 로그인은 사용자 계정을 생성하고 캐릭터, 랭킹, 코인, 뱃지 등 모든 데이터를 하나의 계정에 귀속시키기 위한 기능이다.

### 세부 동작
- 사용자가 최초 가입 시 이메일과 비밀번호를 입력하여 계정을 생성한다.
- 생성된 계정에는 다음 데이터가 연결된다.
  - 캐릭터
  - 온보딩 정보
  - 그룹 정보
  - 미션 수행 기록
  - 코인
  - 뱃지
  - 점수
  - 랭킹
  - 미션 연속 달성 기록
- 사용자가 다른 기기에서 동일한 계정으로 로그인하더라도 기존 데이터를 그대로 이어서 사용할 수 있다.

### 로그인 방식
**이메일 + 비밀번호 로그인**
- 이메일 및 비밀번호 입력
- 사용자 ID 기반 계정 생성 및 관리
- 백엔드 데이터베이스에서 계정 정보 관리

### 사용자 데이터 관리
로그인된 사용자 계정을 기준으로 다음 데이터를 관리한다.
- 캐릭터 / 코인 / 뱃지 / 점수 / 랭킹 / 미션 기록 / 그룹 정보 / 미션 연속 달성

모든 데이터는 계정에 귀속되므로 앱을 삭제하거나 기기를 변경해도 유지된다.

### 구현 방식
- 이메일 + 비밀번호 기반 자체 로그인
- 회원가입 시 사용자 ID 생성
- 백엔드는 사용자 ID를 기준으로 데이터를 조회 및 저장

### MVP 구현 여부
**MVP 구현**
- 이메일 + 비밀번호 로그인
- 사용자 계정 생성
- 로그인 상태 유지

**추후 계획**
- Google 소셜 로그인
- Apple 로그인
- 카카오 로그인

## 4. 온보딩

### 기능 설명
온보딩은 사용자가 그룹에 참여하기 전 자신의 건강 목표와 신체 정보를 설정하는 과정이다.

WITHU는 복잡한 개인정보 입력보다 현재 사용자의 목표와 신체 정보를 빠르게 파악하는 것에 집중한다. 이를 통해 AI는 사용자의 현재 상황에 맞는 개인 맞춤 건강 미션을 생성할 수 있으며, 사용자는 별도의 복잡한 설정 없이 바로 건강관리를 시작할 수 있다.

또한 건강 목표는 시간이 지나며 변경될 수 있기 때문에, 그룹에 참여할 때마다 새로운 목표를 설정할 수 있도록 설계하여 사용자의 현재 상황에 맞는 건강관리를 지속적으로 제공한다.

### 세부 동작
사용자는 새로운 그룹에 참여하기 전 총 3단계의 온보딩을 진행한다.

**STEP 1. 건강 목표 선택**
- 선택 항목: 다이어트 / 벌크업 / 건강관리
- 선택한 목표는 AI가 식단 및 건강 미션의 방향을 결정하는 가장 중요한 기준으로 활용된다.

**STEP 2. 성별 및 나이 입력**
- 입력 항목: 성별, 나이

**STEP 3. 신체 정보 입력**
- 입력 항목: 키, 몸무게
- 신체 정보는 AI가 식단 방향을 개인화하고, 사용자에게 적절한 수준의 건강 미션을 생성하기 위한 참고 데이터로 활용된다.

### AI 역할
AI는 온보딩에서 입력된 건강 목표, 성별, 나이, 키, 몸무게를 종합적으로 분석하여 사용자에게 적합한 건강관리 방향을 설정한다.

수집된 정보는 이후 다음 기능에서 활용된다.
- 개인 맞춤 건강 미션 생성
- 식단 분석 기준 설정
- 미션 난이도 자동 조절

온보딩은 단순한 정보 입력 과정이 아니라, AI가 개인 맞춤형 건강관리 경험을 제공하기 위한 기준 데이터를 생성하는 과정이다.

### 사용자 가치
사용자는 복잡한 설정 과정 없이 자신의 현재 목표와 신체 정보에 맞는 건강관리를 바로 시작할 수 있다. 또한 그룹이 시작될 때마다 자신의 현재 상황에 맞게 목표를 다시 설정할 수 있어, 같은 친구들과 그룹을 유지하더라도 변화한 목표에 맞는 새로운 AI 미션을 제공받을 수 있다.

### 구현 방식
- 사용자는 새로운 그룹에 참여할 때마다 온보딩을 진행한다.
- 온보딩에서 입력한 정보는 해당 그룹의 AI 개인 맞춤 미션 생성 기준으로 저장된다.
- 그룹은 기본적으로 7일 단위로 운영되며, 사용자가 같은 그룹을 계속 유지할 경우 새로운 주차가 시작되는 시점에 온보딩을 다시 진행하여 건강 목표를 갱신할 수 있다.
- 갱신된 정보는 다음 주차부터 생성되는 AI 미션에 반영된다.

### MVP 구현 여부
**MVP 구현**
- 건강 목표 선택
- 성별 및 나이 입력
- 키 및 몸무게 입력

## 5. AI 개인 맞춤 미션

### 기능 설명
AI 개인 맞춤 미션은 사용자의 건강 목표와 신체 정보를 바탕으로 하루 동안 실천 가능한 식단 미션과 간단한 건강 미션을 생성하는 기능이다.

사용자마다 목표와 신체 조건이 다른 만큼, AI는 획일적인 미션이 아닌 개인에게 적합한 건강 미션을 제공하여 건강관리를 꾸준히 이어갈 수 있도록 돕는다.

### AI 역할

**입력값**
- 건강 목표
- 성별, 나이, 키, 몸무게
- 이전 미션 수행 결과
- 이전 식단 분석 결과

**출력값**
- 사용자별 맞춤 건강 미션
- 식단 미션 + 간단한 건강 미션을 합쳐 하루 3~4개의 미션 생성

### 미션 구성

**식단 미션 (메인)**
사용자의 건강 목표에 맞는 칼로리 조절과 영양 성분 섭취를 중심으로 미션을 생성한다.

예시:
- 아침 식사 챙겨먹기 (1인분)
- 점심 단백질 위주 식단 (닭가슴살 + 채소, 1인분)
- 저녁 탄수화물 줄이기 (밥 0.5인분)
- 어제 밥을 거른 경우 → 오늘 3끼 챙겨먹기 미션 생성

**간단한 건강 미션 (보조)**
일상 속에서 쉽게 실천할 수 있는 건강 습관 미션을 생성한다.

예시:
- 물 2L 마시기
- 점심 식사 후 10분 산책
- 저녁 식사 후 스트레칭 5분

### 미션 생성 예시

| 목표 / 성별 / 나이 / 키 / 몸무게 | 생성 미션 |
|---|---|
| 다이어트 / 여성 / 24세 / 165cm / 60kg | 아침 식사 챙겨먹기 (1인분) · 점심 단백질 위주 식단 (1인분) · 저녁 탄수화물 줄이기 (0.5인분) · 물 2L 마시기 |
| 벌크업 / 남성 / 22세 / 175cm / 65kg | 아침 고단백 식사 인증 (1.5인분) · 점심 탄단지 균형 식단 (1.5인분) · 운동 후 30분 내 단백질 섭취 · 하루 3끼 챙겨먹기 |
| 건강관리 / 여성 / 28세 / 162cm / 55kg | 아침 식사 챙겨먹기 (1인분) · 점심 채소 3가지 이상 포함 (1인분) · 저녁 과식하지 않기 (1인분 이하) · 물 1.5L 마시기 |

## 6. AI 분석 상세

### 기능 설명
AI 분석은 사용자가 수행한 식단 데이터를 분석하여 현재 건강 상태와 미션 수행 여부를 판단하는 기능이다.

분석 결과는 단순히 기록으로 저장되는 것이 아니라, 캐릭터 상태 변화와 다음 개인 맞춤 미션 생성의 핵심 데이터로 활용된다.

### 식단 사진 분석
- 사용자는 아침, 점심, 저녁 식단을 촬영하여 업로드한다.
- 사진 업로드 후 선택적으로 아래 정보를 추가로 입력한다.
  - 음식 이름
  - 섭취량 (예: 0.5인분 / 1인분 / 1.5인분)
- 텍스트 정보와 사진을 함께 활용하여 AI 분석의 정확도를 높인다.

### AI 역할

**입력값**
- 식단 사진, 음식 이름, 섭취량, 사용자 건강 목표, 오늘의 식단 미션

**분석 과정**
AI는 식단 사진과 입력된 정보를 함께 분석하여 다음을 종합적으로 판단한다.
- 음식 종류
- 음식 구성
- 영양 균형
- 건강 목표 적합도

칼로리와 영양소를 정확한 수치로 계산하기보다는 건강 목표에 적합한 식단인지 **방향성을 판단**하는 것에 집중한다.

**출력값**
- 미션 성공 여부
- 식단 피드백
- 영양 균형 결과
- 캐릭터 상태 반영 데이터
- 다음 미션 생성 입력 데이터

### 사용자 가치
사용자는 복잡하게 칼로리를 기록하지 않아도 사진과 짧은 텍스트만으로 자신의 식단을 쉽게 관리할 수 있다. 또한 AI는 단순히 식단을 평가하는 것이 아니라 이후 개인 맞춤 미션에도 분석 결과를 반영하여 지속적인 건강관리를 지원한다.

### 난이도 조절

| 달성률 | 조치 |
|---|---|
| 90% 이상 | 난이도 상승 |
| 50~90% | 현재 유지 |
| 50% 미만 | 난이도 하향 |
| 3일 연속 실패 | 미션 1개로 축소 |

## 7. 그룹 시스템

### 기능 설명
그룹 시스템은 WITHU의 핵심 기능으로, 사용자가 혼자가 아닌 친구들과 함께 건강관리를 지속할 수 있도록 지원하는 기능이다.

기존 건강관리 앱이 개인 기록 중심이라 동기부여를 유지하기 어려웠다면, WITHU는 그룹 기반의 건강관리 경험을 제공하여 서로의 진행 상황을 자연스럽게 공유하고 응원하며 건강한 습관을 오래 유지할 수 있도록 설계하였다.

### 세부 동작
사용자는 새로운 그룹을 생성하거나 기존 그룹에 참여하여 건강관리 챌린지를 시작한다.

그룹에 참여한 모든 사용자는 각자의 건강 목표와 신체 정보에 맞는 AI 개인 맞춤 미션을 제공받으며, 미션 수행 결과는 그룹 피드를 통해 자연스럽게 공유된다.

각 사용자는 서로 다른 미션을 수행하지만, 그룹 내에서는 서로의 캐릭터 상태와 미션 달성 현황을 확인할 수 있어 지속적인 동기부여를 받을 수 있다.

### 그룹 구성
- **방 인원**: 최소 2명 / 최대 4명 / 권장 4명
- 소규모 그룹을 통해 서로의 활동을 쉽게 확인하고 활발한 상호작용이 이루어질 수 있도록 설계한다.

### 그룹 참여 방식

**친구 초대 (MVP)**
- 사용자가 그룹을 생성하면 고유한 그룹 코드가 생성된다.
- 초대받은 사용자는 해당 그룹 코드를 입력하여 같은 그룹에 참여할 수 있다.
- 친구, 연인, 가족, 동료 등 함께 건강관리를 하고 싶은 사람들과 자유롭게 그룹을 구성할 수 있다.

**오픈 매칭 (추후 계획)**
- 사용자가 원하는 건강 목표를 선택하면 같은 목표를 가진 사용자들과 자동으로 그룹이 생성된다.
- 예시: 다이어트 / 벌크업 / 건강관리
- 목표가 유사한 사용자끼리 그룹을 구성하여 건강관리의 지속성을 높이는 것을 목표로 한다.

### 그룹 활동

**그룹 피드**
사용자의 식단 인증, 건강 미션 수행 결과, 캐릭터 상태 변화 등이 그룹 피드에 공유된다. 이를 통해 그룹원들은 서로의 건강관리 과정을 자연스럽게 확인할 수 있다.

**미션 알림**
- 방장은 그룹 생성 시 미션 생성 시간을 설정할 수 있다.
- 방이 생성된 이후에는 그룹원 누구나 미션 생성 시간을 변경할 수 있다.
- 설정된 시간에 모든 그룹원의 개인 맞춤 미션이 동시에 생성된다.
- 그룹원이 미션을 완료하거나 식단 사진을 업로드하면 다른 그룹원에게 푸시 알림이 전송된다.
- 알림은 사용자가 ON/OFF 설정할 수 있다.

**개인 맞춤 미션 수행**
모든 그룹원은 동일한 미션을 수행하는 것이 아니라 AI가 생성한 개인 맞춤 미션을 수행한다. 건강 목표와 신체 정보가 다르더라도 각자의 상황에 맞는 건강관리를 진행할 수 있다.

**그룹 내 수행 현황 공유**
사용자의 미션 수행 여부와 캐릭터 상태가 그룹 내에 공유된다. 이를 통해 별도의 경쟁을 강요하지 않으면서도 서로의 진행 상황을 확인하고 자연스럽게 건강관리 참여를 유도한다.

### 사용자 가치
사용자는 혼자 건강관리를 하는 것이 아니라 친구들과 함께 건강관리 과정을 공유하며 자연스럽게 동기부여를 받을 수 있다. 또한 각자의 건강 목표에 맞는 개인 맞춤 미션을 수행하면서도 그룹 활동을 함께 이어갈 수 있어, 경쟁보다는 함께 성장하는 건강관리 경험을 제공받는다.

### 구현 방식
- 사용자가 그룹을 생성하면 고유한 그룹 코드가 생성된다.
- 다른 사용자는 그룹 코드를 입력하여 해당 그룹에 참여한다.
- 그룹 참여 시 모든 사용자는 온보딩을 진행한 후 AI 개인 맞춤 미션을 생성받는다.
- 미션 수행 결과와 캐릭터 상태는 그룹 피드에 자동으로 반영된다.
- 오픈 매칭 기능은 추후 업데이트를 통해 지원한다.

### MVP 구현 여부
**MVP 구현**
- 그룹 생성
- 그룹 코드 기반 참여
- 2~4인 그룹 구성
- 그룹 피드
- 그룹 내 미션 수행 여부 및 캐릭터 상태 공유

**발표에서 설명**
- 미션 생성 알림 기능

**추후 계획**
- 건강 목표 기반 오픈 랜덤 매칭

## 8. 방 운영

### 세부 동작
그룹에 참여한 모든 사용자는 7일 동안 개인 맞춤 건강 미션을 수행한다.

챌린지 기간 동안 AI는 식단 분석 결과를 기반으로 매일 새로운 미션을 생성하며, 그룹원들은 각자의 건강관리 과정을 함께 이어간다.

7일이 종료되면 방은 자동으로 삭제되지 않으며, 모든 그룹원에게 다음 선택지가 제공된다.
- 계속하기
- 방 나가기

계속하기를 선택한 사용자는 기존 그룹을 유지한 채 다시 7일간 건강관리를 시작한다. 이 과정에서 필요하다면 온보딩을 다시 진행하여 건강 목표나 신체 정보를 변경할 수 있으며, 변경된 정보를 기반으로 AI가 새로운 개인 맞춤 미션을 생성한다.

### 운영 방식

**그룹 유지 기간: 7일**
하나의 건강 챌린지는 7일을 기준으로 운영된다.

**1. 그룹 유지 선택**
- 7일 종료 후에도 그룹은 유지된다.
- 사용자는 기존 그룹을 계속 사용할 수 있으며 새로운 방을 생성하거나 친구를 다시 초대할 필요가 없다.
- **온보딩 갱신**: 사용자는 새로운 챌린지를 시작하기 전에 온보딩을 다시 진행할 수 있다. 변경된 정보는 이후 생성되는 AI 개인 맞춤 미션에 반영된다.

**2. 방 나가기 선택**
- 사용자가 현재 그룹에서 나갈 수 있다. 사용자가 나가도 그룹원이 남아있다면 그룹은 유지된다.
- 모든 사용자가 방을 나가면 해당 그룹은 사라지며, 새로운 그룹에 참여할 경우 다시 온보딩을 진행한다.

### MVP 구현 여부
**MVP 구현**
- 7일 단위 챌린지 운영
- 그룹 유지 + 온보딩 갱신
- 방 나가기

## 9. 캐릭터 시스템

### 기능 설명
캐릭터 시스템은 사용자의 건강관리 결과를 직관적으로 표현하는 WITHU의 핵심 기능이다.

사용자는 자신의 건강관리 결과를 숫자나 통계 대신 캐릭터의 표정과 성장 상태를 통해 쉽게 확인할 수 있으며, 친구들과 서로의 캐릭터를 보며 자연스럽게 건강관리 현황을 공유할 수 있다.

캐릭터는 단순한 꾸미기 요소가 아니라, AI 분석 결과와 미션 수행 결과를 시각적으로 표현하여 지속적인 건강관리 동기를 제공하는 역할을 한다.

### 세부 동작
사용자는 회원가입 시 자신만의 캐릭터를 생성한다. 생성된 캐릭터는 계정에 영구적으로 저장되며, 그룹이 종료되어도 삭제되지 않는다.

사용자가 식단 미션과 건강 미션을 수행하면 AI가 수행 결과를 분석하고, 분석 결과에 따라 캐릭터의 표정이 변경된다. 캐릭터 상태는 그룹원들이 확인할 수 있으며, 이를 통해 서로의 건강관리 현황을 직관적으로 파악할 수 있다.

### 캐릭터 생성
- 회원가입 시 최초 1회 생성
- 기본 커스터마이징 아이템(의상) 선택 가능
- 계정에 영구 저장
- 그룹이 변경되어도 동일한 캐릭터 사용

### 캐릭터 표정 (MVP)
현재 건강관리 상태를 표현하기 위해 3단계 표정을 제공한다.

| 상태 | 표정 | 기준 |
|---|---|---|
| 기쁨 | 😊 | 미션을 꾸준히 수행하고 건강 목표에 맞는 생활을 유지하는 상태 |
| 보통 | 😐 | 기본 상태 |
| 슬픔 | 😔 | 미션 수행률이 낮거나 건강관리 상태가 좋지 않은 상태 |

AI 분석 결과와 미션 수행 결과를 종합하여 표정이 변경된다.

### 캐릭터 레벨
캐릭터는 사용자의 건강관리 지속 정도에 따라 총 5단계의 레벨을 가진다.

| 레벨 | 조건 |
|---|---|
| LEVEL 5 | 7일 연속 달성률 80% 이상 |
| LEVEL 4 | 달성률 70% 이상 유지 |
| LEVEL 3 | 달성률 50~70% |
| LEVEL 2 | 2일 연속 미달성 |
| LEVEL 1 | 4일 연속 미달성 |

레벨은 사용자의 장기적인 건강관리 지속도를 나타내며, 그룹원들도 확인할 수 있다.

**레벨 회복 조건**
- 2일 연속 미션 달성

**회복 방식**
- 1단계씩 회복
- 한 번에 여러 단계 회복 불가

### AI 역할
AI는 사용자의 식단 분석 결과와 미션 달성률을 종합적으로 분석하여 캐릭터 상태를 변경한다.

분석 결과는 다음 항목에 반영된다.
- 캐릭터 표정
- 다음 개인 맞춤 미션 생성

캐릭터는 AI 분석 결과를 사용자가 직관적으로 이해할 수 있도록 시각화하는 인터페이스 역할을 수행한다.

### 사용자 가치
사용자는 복잡한 건강 데이터를 확인하지 않아도 자신의 건강관리 상태를 캐릭터를 통해 직관적으로 확인할 수 있다. 또한 친구들과 서로의 캐릭터를 보며 자연스럽게 건강관리 현황을 공유하고 동기부여를 받을 수 있어, 건강관리를 혼자 하는 것이 아니라 함께 성장하는 경험을 제공받는다.

### 구현 방식
- 회원가입 시 캐릭터를 생성하여 계정에 저장한다.
- 기본 커스터마이징 아이템(의상)을 선택하여 초기 캐릭터를 꾸밀 수 있다.
- AI 식단 분석 결과를 기반으로 캐릭터 상태를 계산한다.
- 미션 달성률에 따라 캐릭터 표정을 변경한다.
- 캐릭터 표정은 그룹 화면에서 실시간으로 확인할 수 있다.
- 그룹 종료 후에도 캐릭터 정보는 유지되며 다음 챌린지에서도 동일한 캐릭터를 사용한다.

### MVP 구현 여부
**MVP 구현**
- 캐릭터 생성
- 기본 커스터마이징 아이템(의상) 구현
- 캐릭터 영구 저장
- 표정 3단계
- 캐릭터 상태 공유

**추후 계획**
- 레벨 시스템
- 의상 오염 시스템
- 캐릭터 커스터마이징 확장
- 캐릭터 애니메이션
